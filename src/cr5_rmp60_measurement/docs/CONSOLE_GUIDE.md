# 控制台与 CSV 导入

启动 `bash launch_console.sh`，即可进入包含“导入已有GUI触发CSV（保留原数据）”按钮的五向标准球实验台。该入口在原工作台上增加数据导入，沿用原拟合、路径检查和执行门控。

## 输入与定位

1. 在模型页确认机器人、五针几何、台面、磁座、球杆和标准球尺寸。
2. 填写当前安装编号、标准球编号、球位编号、机器人地址，选择独立实验目录。新安装需要完成五针几何标定；同一刚体夹具移动 XY 后按原流程重新定位球心。
3. 改变球位时，球心 Z 由台面高度、磁座高度、球杆长度及标准球半径决定。模型值和实际安装应一致。
4. 采集或导入同一固定球位的触发数据。核对模型分支与实体针号，不把机器人点动轴直接当成测针局部方向。

## 导入已有触发 CSV

- 点击导入按钮选择一个固定球位、一个源会话的数据。原 CSV 保持不变。
- 有效触发必须包含 `trigger_di1=1`、有效 `branch`、`trigger_flange_x/y/z/rx/ry/rz` 和 `trigger_joint_1` 至 `trigger_joint_6`。普通 `capture_pose` 不计入触发。
- 分支使用 `z`、`x_pos`、`x_neg`、`y_pos`、`y_neg`。保留源行号、源会话、原物理测针标记和文件哈希；不自动猜针号。
- 重复导入相同源记录时跳过；已导入记录发生变化、身份信息不一致或球位已冻结时拒绝改写。自动采集、点动或等待触发期间不能导入。
- 一个 CSV 包含多个源会话时，命令行可显式选择 `--source-session`；界面导入会要求先整理成单一会话文件。

命令行示例（路径和编号替换为自己的值）：

```bash
source src/cr5_rmp60_measurement/scripts/source_runtime.sh
python3 src/cr5_rmp60_measurement/scripts/import_sphere_gui_contacts.py /path/to/contacts.csv \
  --session-dir /path/to/new-session \
  --installation-id installation_01 \
  --standard-sphere-id sphere_01 \
  --placement-id P0
```

同一批触发被重新整理成不同来源文件时，不应在同一实验目录重复导入。

## 拟合、规划和采集

数据导入成功只说明已保存输入。点击原有拟合入口后，还需要覆盖、可观测性和几何一致性检查。数量达到最低要求不代表已经可以运行。

球位输入后，可搜索五针姿态与完整采点路线；在仿真中检查机器人、测头、全部测杆、测球、磁座、球杆和台面。整批检查通过后才可冻结计划；模型、场景或策略变化后必须重检。

现有采集阶段包括五分支冒烟、安装几何、独立球心锚点和评价批次。真实执行还要求本次安装的 commissioning 证据。导入记录、名义模型检查或仿真通过都不直接授权真实运动。

## 基础标定与点动控制台

运行根目录 `bash launch_calibration.sh`，可打开最新的基础标定界面，使用按住点动、松开停止、DI 触发记录和多选删除记录功能。删除功能先备份原 CSV，再只删除所选记录；正在运动或采集中不能修改记录。默认不自动连接机器人。这里的手动点动并不自动继承标准球完整路径预检，应由操作者确认现场条件。
